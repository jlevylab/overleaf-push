Overleaf to git

Recompile, then commit the project and its PDF straight to GitHub.

Fine-grained, this repository only, with Contents: read and write. Nothing else. Stored in extension storage on this machine.

How it works

  • Projects land in overleaf/<project-id>/.
  • Overleaf needs no token: the extension uses the session you are already signed into.
  • Files you delete in Overleaf are deleted in the mirror, so it stays a true copy.
  • The repo must already exist and have at least one commit.
