How it works

  • By default a project lands in the mirror above, under overleaf/<project-id>/. That needs no per-project setup, which is what makes it work across hundreds of projects.
  • A project that has a repo of its own can be routed there instead, below. Then the button updates the real project rather than a backup nobody reads.
  • Overleaf needs no token: the extension uses the session you are already signed into.
  • In the mirror, files you delete in Overleaf are deleted too, so it stays a true copy. A routed push only adds and updates: the repo holds files Overleaf has never heard of (scripts, .gitignore, CI) and deleting those would be destructive.
  • A routed push does not commit the PDF. In the mirror the id keeps PDFs from colliding; in a project's own repo a stale committed PDF beside the source is how you end up reading an old version.
  • The target repo must already exist and have at least one commit, and the GitHub app must be installed on it.

Projects

Leave a project alone and it goes to the mirror. Give it an owner and a repository and it goes there instead, at the path you choose (blank means the repo root).
